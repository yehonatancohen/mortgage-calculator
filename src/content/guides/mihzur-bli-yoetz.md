## אפשר בכלל לבד?

כן. אין שום דרישה לעבור דרך יועץ, ובנקים מקבלים פניות ישירות. מה שיועץ/ת טוב/ה מביא/ה הוא ניסיון, זמן ומשא ומתן. את רוב העבודה אפשר לעשות לבד, אם יש לכם כמה שעות וסבלנות.

המדריך מסביר את הדרך כולה, ובסוף אומר מתי בכל זאת כדאי לשקול עזרה.

## 7 שלבים למחזור לבד

### 1. בקשו דוח יתרות לסילוק

הדוח מהבנק מפרט את היתרה, הריבית, סוג ההצמדה ועמלת הפירעון בכל מסלול. בדרך כלל אפשר להוציא אותו באתר או באפליקציה של הבנק.

### 2. בדקו אם בכלל משתלם

הזינו יתרה, החזר חודשי ושנים שנותרו ב[מחשבון המחזור](/). אם הוא אומר שהמשכנתא שלכם טובה, אפשר לעצור כאן. אם התוצאה גבולית, המשיכו רק אם אתם מוכנים להשקיע בהשוואה.

### 3. בדקו שאין מחסום

רישום הזכויות, מגבלות המימון וההחזר, וההכנסה. רשימת הבדיקה המלאה ב[למה מחזור משכנתא נדחה](/guides/mihzur-mashkanta-nidcha/).

### 4. הכינו תיק אחד

דוח יתרות, תלושי שכר אחרונים, דפי חשבון, צילום תעודות זהות, ונסח טאבו או אישור זכויות. תיק מסודר מקצר כל פגישה בבנק.

### 5. בקשו הצעות משלושה בנקים

מהבנק הקיים ומשניים נוספים. בקשו מכולם הצעה **לאותו סכום ולאותה תקופה**, כדי שאפשר יהיה להשוות. אפשר לבקש גם תמהיל מוצע, אבל השוו קודם על אותו בסיס.

### 6. השוו בטבלה אחת

| | בנק א | בנק ב | בנק ג |
|---|---|---|---|
| ריבית פריים (פריים ± מרווח) | | | |
| קבועה לא צמודה | | | |
| קבועה צמודה | | | |
| משתנה (עוגן + מרווח) | | | |
| החזר חודשי ראשון | | | |
| סך התשלומים עד הסוף | | | |
| עמלות פתיחה ושמאות | | | |

השוו גם לממוצעים ב[ריבית משכנתא היום](/ribit-mashkanta-hayom/). הצעה גבוהה מהממוצע היא סימן שיש מקום למשא ומתן.

### 7. נהלו משא ומתן וסגרו

הציגו לבנק המועדף את ההצעה הטובה ביותר שקיבלתם, ובקשו שישפר. לפני הפירעון, תנו לבנק הקיים הודעה מוקדמת של עשרה ימים לפחות, כדי לא לשלם עמלה על הודעה מאוחרת.

## מתי בכל זאת כדאי עזרה

- **יתרה גדולה ותקופה ארוכה.** כל שבריר אחוז בריבית שווה הרבה כסף, וניסיון במשא ומתן יכול להחזיר את עלות הייעוץ.
- **תמהיל מורכב.** כמה מסלולים, מסלולים צמודים, או מסלול קבוע עם עמלה גבוהה שצריך להחליט אם להשאיר.
- **מצב חריג.** הכנסה לא קבועה, עצמאים, בעיית רישום או היסטוריית אשראי.
- **אין לכם זמן.** פגישות בכמה בנקים לוקחות ימים.

אם אתם בוחרים יועץ/ת, ראו [איך לבחור יועץ משכנתאות](/guides/eich-livchor-yoetz-mashkantaot/).

## שאלות נפוצות

**האם בנק נותן ריבית פחות טובה למי שמגיע בלי יועץ?**
אין לזה כלל. מה שמשפיע הוא הפרופיל שלכם והתחרות. הצעה מתחרה מבנק אחר היא הכלי החזק ביותר, עם יועץ או בלעדיו.

**לכמה סניפים לפנות באותו בנק?**
בדרך כלל אחד מספיק. חלק מהבנקים מפעילים גם מוקד משכנתאות טלפוני או דיגיטלי, ואפשר לבקש הצעה גם שם ולהשוות.

**כמה זמן לוקח מחזור לבד?**
זה תלוי בבנקים, בשמאות וברישום. שאלו כל בנק כמה זמן לוקח התהליך אצלו, ותכננו כמה שבועות.
